### 1. Intended Solution

Extracting the archive file gives us

```
dar---         9/17/2025  11:35 PM                fonts
dar---         9/17/2025  11:35 PM                img
-a----         9/19/2025  10:03 AM       17146594 DrillBabyDrill.exe
-a----         9/19/2025   9:58 AM          11426 DrillBabyDrill.py
-a----         9/17/2025  11:27 PM            414 README.txt
```


Launching the exe shows it's a simple game made with pygame, with the relevant source code in the `.py` file.

![Game Preview](/assets/img/posts/flare12/Drill-Baby-Drill.png)

Since our task is to avoid all the boulders, searching for `boulder` in the source leads us to this snippet on line 212:

```py
        boulder_layout = []
        for i in range(0, tiles_width):
            if (i != len(LevelNames[current_level])):
                boulder_layout.append(random.randint(2, max_drill_level))
            else:
                boulder_layout.append(-1)
```

Essentially, boulders are located at various depths on every column except the one who's index matches the length of the level name. There are 5 level names, all american states, and the order in which they appear is randomized every time, right before the game loop starts.

```py
LevelNames = [
    'California',
    'Ohio',
    'Death Valley',
    'Mexico',
    'The Grand Canyon'
]
```

All that's left to do is dig to the bottom on the correct column of each level, until finally, we get the flag.

![Winning Screen](/assets/img/posts/flare12/Drill-Baby-Drill-Flag.png)

### 2. Faster Solution

The order of the levels serves to complicate the process of discovering the solution, but the flag you get is always the same.

```py
LevelNames = [
    'California',
    'Ohio',
    'Death Valley',
    'Mexico',
    'The Grand Canyon'
]

def GenerateFlagText(sum):
    key = sum >> 8
    encoded = "\xd0\xc7\xdf\xdb\xd4\xd0\xd4\xdc\xe3\xdb\xd1\xcd\x9f\xb5\xa7\xa7\xa0\xac\xa3\xb4\x88\xaf\xa6\xaa\xbe\xa8\xe3\xa0\xbe\xff\xb1\xbc\xb9"
    plaintext = []
    for i in range(0, len(encoded)):
        plaintext.append(chr(ord(encoded[i]) ^ (key+i)))
    return ''.join(plaintext)

def main():
    sum = 1
    for name in LevelNames:
        sum *= len(name)

    print(GenerateFlagText(sum))

if __name__ == "__main__":
    main()
```
